# Требования к выгрузке событий из 1С

Для команды 1С. Цель: стабильный машиночитаемый формат, чтобы система
видео-сверки надёжно разбирала файлы из `\\dc2\Share\IT\test`.

## Формат файла

- **CSV**, кодировка **UTF-8 с BOM**, разделитель **`;`** (точка с запятой).
  XLSX допустим как запасной вариант, но CSV предпочтительнее — разбирается
  без дополнительных библиотек и не ломается при смене версии Excel.
- Первая строка — заголовки, ровно как в таблице ниже (без переименований).
- Одна строка = одно событие (старт **или** стоп). Не «операция целиком»:
  стоп часто приходит позже старта, отдельным файлом.

## Колонки

| Колонка | Обяз. | Формат | Пример |
|---|---|---|---|
| `op_uid` | да* | уникальный ID операции, одинаковый у старта и стопа | `d2f8c9a1-...` или `РК123-этап2-1` |
| `rk` | да | номер РК | `РК-00123` |
| `stage` | да | производственный этап | `Намотка статора` |
| `executor` | да | исполнитель — ФИО полностью, ровно как в справочнике | `Бободжонов Мансурджон Исманович` |
| `event_type` | да | `start` или `stop` (или `старт`/`стоп` — но всегда одинаково) | `start` |
| `event_time` | да | `ДД.ММ.ГГГГ ЧЧ:ММ:СС`, локальное время сервера 1С | `04.07.2026 14:32:00` |
| `product` | желат. | номенклатура/изделие | `Двигатель АИР80` |
| `workplace` | желат. | рабочее место/участок, если 1С его знает | `Намотка РМ1` |

\* Если уникальный ID операции невозможен — допустимо без него, но тогда
дедупликация и связка старт↔стоп идут по (РК + этап + исполнитель), что
ломается при повторных операциях по тому же этапу. **ID сильно желателен.**

## Правила записи файлов

1. **Имя файла**: `1c_events_ГГГГММДД_ЧЧММСС.csv` (например,
   `1c_events_20260704_143205.csv`). Уникальное имя на каждую выгрузку,
   не перезаписывать существующие файлы.
2. **Атомарность**: писать во временное имя (`*.tmp`) и затем переименовывать
   в итоговое. Иначе наблюдатель может прочитать файл, записанный наполовину.
3. **Только новые события** в каждой выгрузке. Если проще выгружать всё за
   день накопительно — допустимо: система дедуплицирует по `op_uid`
   + `event_type`, но тогда `op_uid` становится обязательным.
4. Время события — фактическое время нажатия старт/стоп оператором,
   а не время формирования выгрузки.
5. Пустые значения — пустая ячейка (не `-`, не `нет`).

## Чего не должно быть

- Объединённых ячеек, итоговых строк, шапок «на несколько строк» (типично
  для печатных форм 1С — нужна именно табличная выгрузка).
- Смены порядка/названий колонок между выгрузками.
- Времени без секунд или без даты.
